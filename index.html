prommer.net Agent Brief Builder

A small tool for clearer handoffs

Turn rough task notes into a clear coding brief.

Give your agent the context it needs, without adding anything you did not say.

01 / Input

Describe the task

Use as much or as little as you have. Empty sections are omitted.

What should change?
Where does the work live?
What must be true when done?
What must stay within bounds?
How should it be checked?

02 / Output

Agent brief

Ready for Claude Code, Codex, or another coding agent. 

Your brief will appear here as you add task details.

No sign-in, model calls, or saved data. Everything runs in your browser.
